Conexión con GitHub

            
Se guarda solo en este navegador. Nunca se sube a la web ni entra en los respaldos.


            

              

              

              

            

            

            

              
              
              Se muestra en puntitos y no se puede leer desde la web.
            


            

              
              
            

            


            

              ¿Cómo saco la clave de acceso? (una sola vez, 2 minutos)
              
    
                
  1. Entra a github.com → tu foto arriba a la derecha → Settings.
    2. 
                
  2. Baja del todo en el menú izquierdo → Developer settings.
    3. 
                
  3. Personal access tokens → Fine-grained tokens → Generate new token.
    4. 
                
  4. Ponle un nombre (ej. panel tienda) y una duración larga en Expiration.
    5. 
                
  5. En Repository access elige Only select repositories → marca Shop.
    6. 
                
  6. En Permissions → Repository permissions busca Contents y ponlo en
                    Read and write. No le des ningún otro permiso.
    7. 
                
  7. Generate token, cópialo y pégalo aquí arriba. GitHub solo te lo muestra una vez.
    8. 
              

              

                Esa clave solo puede editar archivos de ese repositorio: no puede entrar a tu cuenta,
                ni borrarla, ni tocar tus otros proyectos. Si algún día quieres anularla, entra a esa
                misma pantalla de GitHub y pulsa Revoke.

4 · ¿Un teléfono se quedó con la versión vieja?
